# 年度滿意度與通知

整體服務、產品與物流服務各自計算。分母為當年度正式回覆中，選「有使用」且該項給 1 至 5 分的人數。分子為其中給 4 或 5 分的人數。年度以試算表台北時區的接收時間判定。以未四捨五入的比例判斷是否超過 94%，零筆有效評分時顯示「尚無評分」。

1. 在正式試算表開啟「擴充功能 → Apps Script」，將 SatisfactionReport.gs 加到這份試算表的綁定專案。
2. 執行 setupSatisfactionReport，授權讀寫試算表。之後每筆正式回覆寫入「網站回覆」時，「年度滿意度」的公式會更新。
3. 在專案設定的指令碼屬性新增 SATISFACTION_REPORT_EMAIL，填入一個已確認的收件地址。
4. 由負責帳號執行 installHourlySatisfactionEmail 並完成 Google 寄信與觸發條件授權。每小時會寄出當下的年度累計百分比、分子、分母與目標狀態。由同一個負責帳號安裝即可。
5. 如需停止通知，到綁定專案的「觸發條件」刪除 sendHourlySatisfactionEmail 的排程。

報表與寄信專案綁定正式試算表，既有問卷接收端的授權範圍可維持原設定。Google 的時鐘觸發條件可能在整點前後執行。
